## Experiment Design

I want to design the experiments in a way that aligns well with the research questions and state of the current project.

TAB / DB-Bio: Many identifiers left in the text, and usually long documents. 1268 / 2420 records in total, 1254 / 2419 individuals in total, very sparsely distributed. Test split has 127 / 239 records and 126 / 239 individuals. Background knowledge generated by summarization of the documents. Risk scores computed on de-identified documents, risk-aware methods tested on de-identified documents.

Reddit: More stylistic attributes in the text, usually very short texts. 525 records for train / test splits, 40 individuals in total. Another 525 records for synthetic train with the same set of individuals. Background knowledge generated by generated personas, asked question, user's response and an agent's interpretation of the user's response to answer a question whether the user has a certain feature or not. Risk scores computed on the original documents, risk-aware methods tested on the original documents.

We have different types of experiments:
1. Privacy
  1. Exact / Test: We select a subset of the individuals from the dataset as the "target" individuals, and we evaluate the performance of the simple vs. risk-aware methods on these individuals.
  1. Full: We evaluate the performance of the simple vs. risk-aware methods on all the individuals in the dataset.
2. Utility: We assess the utility of the anonymized documents. Given that we want to further conduct privacy-preserving data analysis, we can evaluate the utility of the anonymized documents by training and testing a model on the anonymized documents.
3. Divergence: We can also evaluate the divergence between the original and anonymized documents, which can be a proxy for both privacy and utility.
    1. Cosine similarity: We can compute the cosine similarity between the original and anonymized documents in the embedding space.
    1. BERTScore: We can compute the BERTScore between the original and anonymized documents.
    1. Supervised evaluation: Similar to utility tasks, we train a model on the original documents and test it on the anonymized documents.

Reddit case

- Dataset (train / test splits)
- Anonymized dataset (train / test splits)
- Extra dataset (synthetic dataset)

Reddit supervised divergence:
- Train a model on the original train split, then test it on the original / anonymized test splits.

Reddit privacy:
- Run privacy evaluation on the whole train / test split

Reddit divergence:
- Run divergence evaluation on the whole train / test split

Reddit utility:
- First, train a model on the original train split and test on the test split, and get a baseline score. Then, fine-tune the same model on the anonymized train split, and test it on the anonymized test split.

TAB / DB-Bio case

- Dataset (train / val / test splits)
- Anonymized dataset (train / val / test splits)

Tab supervised divergence:
- Train a model on the original train split, select the best model on val split, then test it on the original / anonymized test splits.

Tab privacy:
- Run privacy evaluation on the whole train / val / test splits

Tab divergence:
- Run divergence evaluation on the whole train / val / test splits

Tab utility:
- First, train a model on the original train split, select the best model on val split, then test on the test split, and get a baseline score. Then, fine-tune the same model on the anonymized train split, select the best model on the anonymized val split, and test it on the anonymized test split.
